# Rubrik Bagian Pendukung (Abstrak, Daftar Pustaka, Lampiran)

> Bagian ini bukan bagian dari Bab 7, tetapi dibahas pada slide yang sama. Dinilai **terpisah** dengan total 100.

## Ringkasan Bobot

| No | Komponen | Bobot |
|---|---|---|
| P1 | Abstrak | 40 |
| P2 | Daftar Pustaka | 30 |
| P3 | Lampiran | 30 |
| | **Total** | **100** |

Skala level: 4 = Sangat Baik (100% bobot) · 3 = Baik (75%) · 2 = Cukup (50%) · 1 = Kurang (25%) · 0 = Tidak ada (0%). Rumus skor: `Skor = (Level / 4) × Bobot`.

---

### P1. Abstrak — Bobot 40

**Checklist indikator**
- [ ] Berupa **satu paragraf** ringkasan yang sangat singkat, **maksimum setengah halaman** dengan spasi 1 **(slide)**
- [ ] Dimulai dengan ringkasan **masalah** **(slide)**
- [ ] Memuat ringkasan singkat **analisis dan desain** **(slide)**
- [ ] Memuat ringkasan kecil tentang **teknologi yang digunakan dan implementasi** **(slide)**
- [ ] Memuat **proses evaluasi dan hasilnya** **(slide)**
- [ ] **Tidak disalin** dari bagian lain dokumen **(slide)**
- [ ] Dapat dipahami berdiri sendiri **(pelengkap)**

| Level | Deskriptor |
|---|---|
| **4** | Satu paragraf ≤ ½ halaman, urutan lengkap (masalah → analisis/desain → teknologi/implementasi → evaluasi/hasil), ditulis ulang dengan kalimat sendiri. |
| **3** | Memenuhi format. Satu unsur kurang (mis. hasil evaluasi tidak disebut) atau sedikit melebihi batas. |
| **2** | Dua unsur penting hilang, terlalu panjang, atau lebih dari satu paragraf. |
| **1** | Sebagian besar disalin dari bagian lain, atau tidak mengikuti struktur sama sekali. |
| **0** | Tidak ada abstrak. |

---

### P2. Daftar Pustaka — Bobot 30

**Checklist indikator**
- [ ] Menggunakan **format APA** **(slide)**
- [ ] Diurutkan menurut **nama belakang penulis** **(slide)**
- [ ] **Semua sumber yang dikutip** di teks tercantum di daftar pustaka **(slide)**
- [ ] **Setiap referensi** di daftar pustaka **dikutip** di dalam naskah **(slide)**
- [ ] Data referensi lengkap dan konsisten **(pelengkap)**

| Level | Deskriptor |
|---|---|
| **4** | Format APA konsisten, urut nama belakang, dan terdapat kecocokan penuh antara sitasi dan daftar pustaka. |
| **3** | Hampir sesuai. Beberapa kesalahan format kecil atau satu-dua ketidakcocokan. |
| **2** | Banyak kesalahan format atau beberapa sumber tidak cocok antara teks dan daftar. |
| **1** | Format tidak mengikuti APA dan banyak ketidakcocokan. |
| **0** | Tidak ada daftar pustaka. |

---

### P3. Lampiran — Bobot 30

**Checklist indikator**
- [ ] Berisi materi yang **berguna diketahui pembaca tetapi tidak esensial** **(slide)**
- [ ] Penomoran memakai **huruf kapital diikuti judul dokumen**, mis. *Lampiran A. Cara Penggunaan Program* **(slide)**
- [ ] Nomor halaman berformat **huruf kapital lampiran diikuti urutan**, mis. **A-12** untuk lampiran A halaman ke-12 **(slide)**
- [ ] **Buku petunjuk pengguna (*user manual*)** disertakan, karena **wajib** di departemen (IF, SIB, MM) **(slide)**
- [ ] Hal esensial tidak ditaruh di lampiran saja (harus ada di bab utama) **(pelengkap)**

| Level | Deskriptor |
|---|---|
| **4** | Penomoran dan format halaman sesuai, user manual ada, dan isi lampiran tepat (nice-to-know). |
| **3** | User manual ada. Ada kesalahan kecil pada penomoran atau format halaman. |
| **2** | User manual ada tetapi format lampiran tidak sesuai, atau isi esensial tertinggal di lampiran. |
| **1** | User manual tidak ada. |
| **0** | Tidak ada lampiran. |
